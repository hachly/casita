# Casita

An iPhone app where each code opens its own private space, and no space can tell whether other spaces exist.

## Language

### Threats

**Phone check**:
Someone gets the owner to unlock the phone and looks through it, often while the owner watches.
_Avoid_: search, inspection

**Theft**:
Someone takes the phone and tries to get into it without the owner's codes.

**Forensic extraction**:
Someone copies the phone's storage with forensic tools and tries codes against it, on the phone or offline.
_Avoid_: hack, lab copy

### Spaces

**Space**:
A self-contained area of Casita with its own photos, files and web logins, opened by its own code. Every space looks and works the same.
_Avoid_: vault, account, profile, phone, home screen, desktop

**Everyday space**:
The space a person is comfortable showing others, and the only space Face ID can open.
_Avoid_: decoy space, fake space, public space

**Top space**:
The one space with no parent, holding the owner's real data, from which every other space can be opened. The app never labels it.
_Avoid_: admin space, private space, real space, master space

**Reserved storage**:
The fixed amount of iPhone storage Casita sets aside for all spaces together. Its size changes only when the owner chooses, never because of what is inside.
_Avoid_: box, pool, vault

**Room**:
The part of the reserved storage that one space has been given to fill.
_Avoid_: quota, allocation

**Parent space / Child space**:
A parent space holds the keys to the spaces created under it, its child spaces, and gives each child its share of room. A child space knows nothing about its parent or its siblings. Any space can be a parent.
_Avoid_: subspace, nested space, sub-account

### Unlocking

**Code**:
The secret that opens one space, entered as digits, dots or a password.
_Avoid_: passcode (reserved for the iPhone's own passcode), PIN, login

**Unlock method**:
One of the three ways to enter a code: number pad, dots or keyboard.
_Avoid_: lock type

**Dots**:
The unlock method where the code is a path drawn through a grid of dots.
_Avoid_: pattern, maze

**Entry screen**:
The one screen where a code for any space is entered.
_Avoid_: lock screen (reserved for the iPhone's Lock Screen), login screen

**Recovery key**:
A long secret shown once at setup that lets a person restore their spaces on a new phone.
_Avoid_: backup code, master password

### Inside a space

**Save to Casita**:
The share-sheet action in other apps that saves a photo, video or file straight into a space after its code is entered.
_Avoid_: share extension, import (reserved for bringing things in from inside Casita)

**Web**:
The tile in a space that holds that space's web bookmarks, such as Instagram, Telegram, X and Reddit, each with logins that belong to that space only.
_Avoid_: Browser, Social, Chat (as separate tiles), web container
